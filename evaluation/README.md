# Evaluation Data

The initial public release includes only the repository-authored deterministic
fixtures, fixed scenarios, offline Type D cases, and continuous simulation
artifact listed below. These public candidates are synthetic and do not
contain transcripts from real pilot participants.

Public candidates:

- `fixtures/`
- `scenarios/`
- `type-d-spike/`
- `live/l4-l5-continuous-simulation.json`

The following paths remain available locally for tests or later review but are
excluded from the initial public tree:

- `30min/`
- `real-analyzer/`
- `golden/v2/`
- `context-spike/`
- `live/preflight/`
- `live/sessions/`
- `live/*real*.json`
- `stt/`
- `runs/`
- `rescored/`

Do not add real meeting audio, participant transcripts, feedback, observer
notes, or private session artifacts to this directory.
